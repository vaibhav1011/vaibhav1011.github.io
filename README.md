# Vaibhav Salaklan — Portfolio

My personal portfolio site — a single-page site covering my background, work experience, 
skills, and projects.

🔗 **Live site:** https://vaibhav1011.github.io

## Built with
- React (Vite)
- Tailwind CSS
- Framer Motion

## Sections
- Home
- About
- Work Experience
- Skills
- Projects
- Leadership & Achievements
- Contact

## Running locally
```bash
npm install
npm run dev
```

## Deploying
```bash
npm run build
npm run deploy
```
